🌤️ SkyCast - Django Weather App

A modern weather application built with Django that fetches real-time weather data using the OpenWeatherMap API.

🚀 Features
Search weather by city name
Real-time temperature (°C)
Wind speed (km/h)
Humidity & visibility data
Sunrise & sunset time
Day/Night detection
Clean UI with responsive design

🛠️ Tech Stack
Python
Django
HTML, CSS, JavaScript
OpenWeatherMap API
